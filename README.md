# Activity Recognition

A Python-based machine learning project for recognizing human activities from sensor data.

## Overview

This project explores the main steps of a machine learning pipeline, including:

* Data preprocessing
* Data cleaning
* Feature extraction
* Feature selection/reduction
* Model training
* Activity classification
* Model evaluation

## Technologies

* Python
* NumPy
* Scikit-learn
* Matplotlib

## Activities

The model is trained to classify different types of human activities based on sensor data.
